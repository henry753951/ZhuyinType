# 設定視窗的資訊架構

本文件寫設定視窗的整體架構：側欄有哪些項目、每一頁放什麼、哪些設定放到下一層，以及頁面之間怎麼連結。各頁的細節見 [DESIGN.md](DESIGN.md) §4.5。

## 1. 原則

1. **側欄只放幾個大類。** 側欄是使用者找東西的第一層，項目越少越容易掃過。九項以小灰字的段落標題分成四段：概覽（介紹、分析）；輸入（打字、選字、字詞）；外觀（視窗與提示）；一般（快捷鍵、進階、關於）。每一項的名稱就是它管的事，不需要說明。
2. **一頁只放常改的設定。** 打開一頁，看到的是多數人會調整的選項，每項一行說明。頁面不超過一個螢幕高太多。
3. **細節與少改的設定放到下一層。** 一頁中以「›」結尾的列（和系統設定相同）開啟下一層：清單（自訂詞、記住的字詞）、一整組開關（模糊音）、說明較多的功能（前文），以及少改的按鍵（標點與符號、其他打字的按鍵）。列上直接顯示目前的狀態，例如「模糊音　已開啟 2 項 ›」，不必點進去也知道。下一層的上方有「‹ 選字」回到上一層。
4. **一個功能只在一個地方。** 功能的開關、它的按鍵、說明與示範放在一起：先是功能列（名稱、可以換行的說明與開關），下面縮排一列「快捷鍵」放按鍵欄位，功能關閉時不顯示這一列。例如「列出修正的字」和「按錯鍵修正」放在一起；「打出注音本身」在「選字 › 改字」。不在兩頁各放一份會互相矛盾的設定，也不在每一列放跳到「快捷鍵」的按鈕：每頁的頁尾有一個文字連結「在快捷鍵總覽中查看全部按鍵」。
5. **按鍵在功能旁邊設定；「快捷鍵」是索引。** 每個可以自訂按鍵的功能，在自己那一頁就有按鍵欄位（§3 的元件）與「還原預設」。「快捷鍵」頁把所有動作與按鍵列成一張唯讀的表：可以搜尋、看按鍵衝突，和預設不同的列標「已自訂」；點一下任何一列，到功能的頁面並標出它的「快捷鍵」列。頁尾有「全部還原…」。開關只在功能的頁面：總覽中關閉的功能變暗，列尾是安靜的「已關閉 ›」。無法更改的按鍵收在最下方的「固定的按鍵」。兩處修改的是同一份資料。
6. **功能是否開啟只有一個來源。** 例如「單按 Shift 切換中英」在「打字」與「快捷鍵」都看得到，兩處讀寫同一個設定。功能被其他設定關掉時（例如關閉「顯示注音」後，「點注音列打出注音」沒有作用），相關的列變暗，寫一行原因，並連到那個設定。
7. **基本與進階。** 每個人都可能調整的放在前三頁；只有特定需求才用的（改字記錄、在候選字視窗顯示組字的 App、回復預設設定）放在「進階」。
8. **介紹與分析。** 「介紹」是第一次打開設定時看到的首頁：打字過程的示範、主要功能卡片（各連到所在頁面），以及幾項目前設定的摘要。「分析」是使用回顧：打了多少字、改了幾次、輸入法的反應時間；計數的開關與清除也在這一頁。

### 2.1 每個設定放在哪裡、為什麼

| 設定 | 位置 | 理由 |
|---|---|---|
| 空白鍵 | 打字 | 常改；影響每一次打字 |
| Esc | 打字 | 和空白鍵同屬「打完以後怎麼收尾」 |
| 標點按法 | 打字 | 從 Windows 或 macOS 換過來的人第一天就會改 |
| ⌃ 中文標點、⌥ 鍵上的符號 | 打字 › 標點與符號 | 少改；和標點按法是同一個功能 |
| 單按 Shift 切換、Caps Lock 打英文、中英提示、開始輸入時使用英文 | 打字 › 中英切換 | 同一個功能；常改的是切換鍵 |
| 送出並換行、刪掉一個詞 | 打字 › 編輯組字 | 組字中的編輯按鍵 |
| 固定的打字按鍵 | 打字 › 所有打字的按鍵 | 唯讀，供查詢 |
| 游標在句中時改、台／臺 | 選字 | 影響選出來的字 |
| 按錯鍵修正、列出修正的字 | 選字 › 按錯鍵 | 修正清單是按錯鍵修正的一部分 |
| 模糊音 | 選字 › 模糊音 | 五個開關，少改，放在下一層，列上顯示狀態 |
| 參考游標前的文字 | 選字 › 前文 | 一個開關在本頁；說明較多，放在下一層 |
| 打出注音本身、選取加入自訂詞、送出後刪掉重打 | 選字 › 改字 | 都是改正選字的方法 |
| 排列、字級、間距、每頁的候選字、選字鍵 | 視窗與提示 | 候選字視窗的樣子；有預覽 |
| 翻頁 | 視窗與提示 | 在清單中使用；選字鍵與每頁數量在旁邊 |
| 顯示注音、點注音列、標出修正的讀音、只列一個字、單字與修正按鈕 | 視窗與提示 › 清單的內容 | 清單上出現的東西 |
| 位置、外觀、動畫 | 視窗與提示 › 位置與外觀 | 設一次就很少再改；套用到所有浮動視窗 |
| 記住選過的字詞、記住的字詞清單 | 字詞 | 個人字詞的資料 |
| 自訂詞清單 | 字詞 › 自訂詞 | 個人字詞的資料 |
| 記錄使用統計、清除統計 | 分析 | 和統計的結果放在一起 |
| 改字記錄 | 進階 | 給想協助改進選字的人；預設關閉 |
| 在候選字視窗顯示組字的 App | 進階 › | 只有少數 App 需要 |
| 回復預設設定 | 進階 | 少用、影響大 |
| 自動檢查、自動安裝更新 | 關於 | 和版本放在一起，和系統的「軟體更新」相同 |

## 3. 按鍵欄位（同一個元件用在每一處）

功能頁、「快捷鍵」總覽與示範的按鍵標示都使用同一個元件：

- **樣式**：每個按鍵畫成按鍵圖示，修飾鍵各自一個（⌃ ⌥ ⇧ ⌘ 依系統的順序），樣式在每一頁都相同。
- **多個按鍵**：一個動作最多三個按鍵，以「A 或 B」顯示。指標移到欄位上時出現「＋」（加入另一個按鍵）；按鍵上按右鍵可以「改按鍵」「移除這個按鍵」「全部還原成預設值」。
- **錄製**：點一下按鍵開始錄製，外框以強調色緩慢明暗變化，顯示「按下新的組合…」；按住修飾鍵時即時顯示已按下的鍵；按 Esc 取消。接受時按鍵輕輕彈一下並出現綠色勾號；拒絕時欄位輕微左右晃動，下方以紅字寫出原因。「減少動態效果」時改成淡入淡出。
- **組合**：支援修飾鍵加一個鍵。兩段式按鍵（先按一個組合，再按另一個）這一輪沒有做；需要時在 ControllerCore 加一個等待第二鍵的狀態即可，不需改引擎。
- **還原**：按鍵和預設不同時，功能頁的「快捷鍵」列上有文字按鈕「還原預設」，相同時不顯示；右鍵選單也可以還原。總覽只標「已自訂」，不在那裡還原。
- **版面不動**：「＋」的位置一直保留在按鍵左邊，指標移過時只改變透明度；錄製、接受與拒絕也不改變欄位的高度。
- **fn 鍵**：筆電上以 fn 打的鍵照鍵盤上印的顯示，例如「fn ↓」（Page Down），工具提示寫出全名。
- **衝突**：錄製時拒絕已用於其他動作的組合，訊息寫出那個動作的名稱。已存在的衝突（例如移轉舊設定，或打開一個功能後）也會標出：衝突的按鍵以系統紅色的細外框與淡紅底顯示，下方一行紅字「也用於「列出修正的字」」，附「改按鍵」與「前往」。「快捷鍵」總覽的最上方列出所有衝突。
- **停用**：功能關閉時，欄位變暗、不能編輯，列上寫「已關閉：⌃U 交給 App」。
- **不會超出版面**：多個按鍵在欄位寬度不夠時換行並靠右對齊；說明文字換行；按鍵名稱不截斷，動作名稱過長時截斷並以工具提示顯示全文。

資料：每個動作存成有順序的按鍵清單（第一個是主要的按鍵）。舊版每個動作一個按鍵的設定，讀取時當成只有一個按鍵的清單，第一次修改後改存新格式。引擎不變。

## 4. 連結

- 每頁頁尾有一個文字連結「在快捷鍵總覽中查看全部按鍵」；不在每一列放跳轉按鈕。
- 「快捷鍵」的每一列連到功能的「快捷鍵」列；按鍵衝突連到相關的列；被其他設定關掉的功能，列上寫原因並連到那個設定。
- 每一個連結到達時都用同一個提示（DESIGN.md §4.5「到達提示」）：捲到目標約在上方三分之一，目標列的底色亮一次，段落標題同時變成強調色。
- 「介紹」的功能卡片與設定摘要連到所在的頁面。
- 下一層頁面的上方是「‹ 上一層的名稱」；側欄維持選取上一層的項目。

## 5. 和現在相比

| 現在 | 提案 | 使用者得到什麼 |
|---|---|---|
| 一般（按鍵、選字、模糊音、中英切換） | 拆成「打字」與「選字」 | 名稱就說明內容；一頁的設定變少 |
| 快捷鍵（設定按鍵的地方） | 按鍵在各功能旁邊設定；「快捷鍵」改為總覽 | 改一個功能時，開關、按鍵、說明都在眼前 |
| 前文（側欄一項） | 選字 › 前文 | 前文是選字的一部分；側欄少一項 |
| 自訂詞、記住的字詞（側欄兩項） | 字詞 › 自訂詞、記住的字詞 | 個人字詞集中；列上顯示筆數 |
| 視窗與提示（所有選項在一頁） | 常改的在本頁，位置與外觀在下一層 | 預覽與常改的選項在同一個畫面 |
| 模糊音（一頁中五列） | 選字 › 模糊音 | 頁面變短；列上顯示已開啟幾項 |
| 改字記錄（進階） | 不變 | |
| 使用統計 | 分析 | 結果與開關在一起 |

## 6. 狀態

2026-10-28 核准，已依本文件實作（DESIGN.md §4.5）。原本的示意圖程式已移除；`ZhuyinType --render-ui <目錄>` 在畫面外繪製每一頁與每個下一層頁面，各以最窄（頁面寬 440 pt）與較寬（860 pt）兩種寬度、淺色與深色，另有非預設按鍵、關閉功能與按鍵衝突、按鍵欄位各種狀態的版本；整個視窗（含側欄）也各畫一般、最小（640 × 440）與較大（1280 × 900）三種大小。
