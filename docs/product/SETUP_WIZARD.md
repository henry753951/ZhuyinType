# 設定嚮導

這份文件是「設定嚮導」的流程與分鏡。程式在 `platforms/macos/Sources/ZhuyinTypeApp/UI/Wizard/Flow/`（流程）與 `UI/Wizard/Practice/`（練習欄位）；步驟、習慣組合與課程是設定的資料（SETTINGS_API.md），嚮導本身不寫設定的內容。分鏡的圖片是設計時畫的靜止畫面（`--render-ui <資料夾> --only storyboard`）；實際的畫面以 `--render-ui <資料夾> --only wizard` 產生。

## 1. 目的

設定嚮導讓第一次使用的人在幾分鐘內：

- 選好自己原本習慣的打法（標點、空白鍵、中英切換、選字與翻頁）；
- 在嚮導裡實際打幾個字，確認每個選擇的效果；
- 最後看到一份「原本 → 改成」的清單，確認後才套用；
- 留下一頁「你會用到的按鍵」，之後可以在「介紹」再看。

嚮導不另外寫設定的內容。每一步、每個選項、確認頁的清單與按鍵總覽，都從設定的描述（之後的 SETTINGS_API.md）產生，所以新增一個功能時只要寫好它的說明與練習，就會出現在嚮導中。

## 2. 流程

```text
歡迎（快速設定／完整導覽）
  → 習慣組合（Windows 注音的習慣、macOS 注音的習慣、ZhuyinType 預設、自訂）
  → 課程 1 … 課程 N（每一課：說明與小動畫、選擇、練習、完成）
  → 確認要套用的設定（原本 → 改成，可以逐項改回或調整）
  → 你會用到的按鍵
```

- 「快速設定」只走標為「基本」的課程（5 課，約 2 分鐘）；「完整導覽」走全部的課程（11 課）。
- 每一步都有「上一步」「略過這一步」與右上角的「全部跳過」。全部跳過時不改任何設定，直接結束。
- 嚮導中的所有變更都先存在一份暫存的設定裡，練習欄位使用這份暫存設定；按「套用」之前，系統中的輸入法完全照原本的設定運作。

## 3. 什麼時候出現

| 時機 | 內容 |
|---|---|
| 安裝後第一次使用 | 從歡迎開始，只開一次；不在打字時自己打開視窗 |
| 更新後加入了新的課程 | 不自己打開；輸入法選單與「介紹」出現「新功能導覽」，只走新的課程 |
| 「介紹」頁的「開始設定嚮導」 | 從歡迎開始，習慣組合預先選「自訂」（從目前的設定開始） |
| 輸入法選單的「設定嚮導…」 | 同上 |

除此之外不會自己出現。已完成或已略過的版本記在設定中。

## 4. 每一課的組成

每一課依序是：

1. **標題與一句說明**，旁邊是這個功能的小動畫（沿用設定頁的 ⓘ 示範與「視窗與提示」的小動畫）；
2. **選擇**：
   - 互斥的方式是一組分段控制或選項卡，例如標點按法、排列；
   - 可以同時有效的方式是一組勾選，例如翻頁的 Tab、fn ↓、⌥↓、在頁底按 ↓；
   - 「自行設定…」打開同一個按鍵欄位，可以指定其他按鍵；
3. **練習**：一個輸入欄位與一個任務，例如「打出「好，謝謝。」」。切換上面的選擇時，練習欄位立即照新的設定運作，可以直接比較；
4. **完成**：任務達成時欄位外框變成綠色，出現「完成」，「下一步」可以按。任務也可以略過。

## 5. 課程與練習

課程的順序固定；「基本」的課程在快速設定與完整導覽中都會出現，其餘只在完整導覽中出現。完成的判斷都在嚮導內的組字引擎上檢查（見 §8）。

| 課程 | 範圍 | 選擇 | 練習任務 | 完成的判斷 |
|---|---|---|---|---|
| 打字與空白鍵 | 基本 | 空白鍵：送出並輸入空白／輸入空白，不送出／開啟候選字視窗 | 打出「今天天氣很好」 | 欄位的文字是「今天天氣很好」 |
| 標點 | 基本 | 標點按法：Windows（⌃ 打中文標點）／macOS（⇧ 打中文標點） | 打出「好，謝謝。」 | 欄位中有「，」與「。」 |
| 中英切換 | 基本 | 單按 Shift（左右、左、右、不使用）；Caps Lock 打英文 | 切換到英文打「OK」，再切回中文打「好」 | 欄位是「OK好」，且切換過兩次 |
| 選字與翻頁 | 基本 | 排列：直式／橫式；同時有效的翻頁方式：Tab、fn ↓、⌥↓、在頁底按 ↓ | 打 ㄇㄧㄥˊ，翻到下一頁，選第 12 個字「暝」 | 選到「暝」，且翻過頁 |
| 改字 | 基本 | 游標在句中時改：右邊的字／左邊的字 | 把「我在家」改成「我再家」 | 欄位是「我再家」，且是從清單選的 |
| 按錯鍵與修正清單 | 完整 | 按錯鍵修正：關閉／標準／積極；列出修正的字的按鍵 | 照提示故意按錯一個鍵，再用 ⇧↑ 找到正確的字 | 用修正清單選到正確的字 |
| 模糊音 | 完整、可略過 | ㄗ／ㄓ、ㄘ／ㄔ、ㄙ／ㄕ、ㄣ／ㄥ 等勾選 | 以模糊的讀音打出指定的字 | 選到指定的字 |
| 前文 | 完整 | 參考游標前的文字：開／關 | 在已經有「天氣」的欄位接著打出「很好」 | 選字結果用到前文 |
| 加入自訂詞 | 完整 | 選取的按鍵（⇧← ⇧→） | 選取「王小明」，按 Return 加入 | 自訂詞加入暫存資料 |
| 候選字視窗的樣子 | 完整 | 字級、間距、每頁的候選字、選字鍵、位置、外觀、動畫 | 沒有任務，即時預覽 | 按「下一步」 |
| 改字記錄 | 完整、進階 | 記錄改字：開／關；一併記錄游標前的文字 | 沒有任務，說明記錄的內容與存放的位置 | 按「下一步」 |

新功能加入嚮導時，只要在它的設定描述旁寫好：一句說明、小動畫、選擇、一個或幾個練習任務與完成的判斷，並標明「基本」「完整」「可略過」或「進階」。

## 6. 習慣組合

習慣組合是一組選擇的資料，套用時產生一份變更，和確認頁使用同一份清單，所以每一項都看得到、都能改回。名稱描述習慣本身，不使用其他產品的名稱或圖示。組合只放有出處的行為；沒有出處的設定不放進組合，保留目前的值（出處見 [PRESETS.md](PRESETS.md)）。

| 設定 | Windows 注音的習慣 | macOS 注音的習慣 | ZhuyinType 預設 |
|---|---|---|---|
| 空白鍵 | － | 開啟候選字視窗 | 送出並輸入空白 |
| 單按 Shift 切換中英 | 開（左右 Shift） | 關 | 開（左右 Shift） |
| Caps Lock 打英文 | － | 開 | 開 |
| 開始輸入時使用英文 | 關 | － | 關 |
| 標點按法 | － | －（只有 2017 年的第二手資料，見 PRESETS.md） | Windows |
| ⌃ 加符號鍵打中文標點 | 開 | － | 開 |
| ⌥ 加數字或符號鍵打鍵上的符號 | － | 開 | 開 |
| 選字鍵 | 1–9 | 1–9 | 1–9 |

「－」表示這個組合不改這項設定，維持目前的值。「自訂」從目前的設定開始，不改任何設定。兩個組合只放兩種系統內建注音輸入法有出處的行為；每一項的出處，以及找不到出處而沒有放進組合的項目（例如排列與翻頁的按鍵），見 [PRESETS.md](PRESETS.md)。

可以同時有效的方式（例如翻頁的幾個按鍵）在課程中勾選，衝突時由按鍵的衝突檢查決定；互斥的方式（例如標點按法、排列）是一個選擇。每個功能有哪些常見的方式，整理在 SETTINGS_API.md 的「方式一覽」中。

## 7. 確認頁與按鍵總覽

- **確認要套用的設定**：列出這次嚮導中改變的每一項設定，一列一項，寫「原本」與「改成」，旁邊有「改回」。點設定名稱可以就地調整（同一個選擇元件）。這份清單由暫存設定與原本設定的差異產生，不另外撰寫。按「套用」才寫入設定；「全部捨棄」不改任何設定並結束嚮導。
- **你會用到的按鍵**：依套用後的設定產生的一頁按鍵表（按鍵圖示與動作），只列有開啟的功能。這一頁之後可以在「介紹」再打開。

## 8. 練習欄位怎麼運作

輸入法無法透過系統的輸入法框架在自己的視窗中打字，所以練習欄位直接在嚮導裡運作：

- 嚮導建立一個自己的組字核心（和輸入法使用同一個 `ControllerCore` 與引擎），文字送到嚮導內的欄位，候選字視窗畫在欄位下方（和「視窗與提示」的預覽是同一個元件）；
- 練習欄位有焦點時，嚮導攔下按鍵（包括 Shift 單按、Caps Lock 與 fn 組合），交給這個核心處理；
- 這個核心使用暫存設定與暫存的使用者資料，練習中打的字、選的字與加入的自訂詞都不寫入你的資料，按「套用」時只套用設定（加入自訂詞的練習會問是否保留那個詞）；
- 系統的安全輸入開啟時（例如另一個視窗正在輸入密碼），練習欄位照常運作，因為它不經過系統的輸入法框架。

做不到的事：練習欄位只能示範 ZhuyinType 自己的行為，不能示範在其他 App 中的情況（例如某個 App 需要把組字顯示在候選字視窗上方）；這些在對應的課程中以文字說明。

### 練習欄位的元件

練習欄位已經完成，程式在 `platforms/macos/Sources/ZhuyinTypeApp/UI/Wizard/Practice/`。

- **使用方式**：`PracticeField(settings: SettingsSnapshot(sandbox), task: lesson.tasks[0], initialText:, onProgress:, onComplete:)`。
  - `settings` 是設定描述的快照（`SettingsSnapshot`，SETTINGS_API.md）。換成新的值時立即生效，組字中也一樣；清單開著時，同一種清單以新的設定重新開啟，回到第一頁。
  - `task` 是課程的 `PracticeTask`（題目、提示與完成的判斷）；換成別的題目時，欄位清空，從 `initialText`（例如前文課程的「天氣」）重新開始。
  - 欄位在每次改變後更新 `PracticeOutcome`，交給任務的判斷：
    - `text`：欄位的文字（送出的與組字中的）；
    - `events`：發生過的事，`open`（開啟清單）、`page`（翻頁）、`pick`（選字）、`correct`（選到的字和原本的不同）、`corrections`（開啟修正清單）、`mode`（中英切換）、`phrase`（加入自訂詞）；
    - `picks`：從清單選的字；
    - `sent`、`corrected`、`correctionPicks`、`phrases`：只有送出的文字、改成的字、從修正清單選字的次數與加入的自訂詞。
  - `onProgress` 收到 `PracticeProgress`（目前的結果、是否完成，以及加入的自訂詞與讀音，讓嚮導最後詢問是否保留）；`onComplete` 在判斷第一次成立時呼叫一次。
- **任務**也可以用現成的三種寫法產生，一個任務可以組合幾個目標（`PracticeGoal`），全部達成時完成：
  - 打出一句：`PracticeTask.sentence("今天天氣很好")`，送出的文字等於這一句時完成；
  - 用某個按鍵或動作：`PracticeTask.action(說明, 目標…)`。目標可以是開啟候選字清單、翻頁、選字（可以指定字）、改字、從修正清單選字、中英切換幾次，或欄位中有某些字（例如標點）；
  - 加入自訂詞：`PracticeTask.userPhrase("王小明")`，這個詞加入練習用的資料時完成。
- **按鍵**：欄位有焦點、嚮導視窗在最前面時，欄位比視窗先收到每個按鍵（包括 Shift 單按、Caps Lock 與 fn 組合），交給它自己的 `ControllerCore`。
  - 核心交給 App 的按鍵，由欄位像一般的單行文字欄位處理：打出字元，⌫ 刪除前一個字。
  - Return 與 Esc 留在欄位中，不會按下嚮導的按鈕。
  - 沒有組字時，Tab 移到下一個控制項，⌘ 組合鍵交給選單。
- **畫面**：
  - 組字的底線與強調色由核心設定，和在 App 中相同。
  - 候選字視窗、提示與中英提示是輸入法本身的元件，依同樣的規則放在組字開頭的下方（或上方），但畫在嚮導視窗之內。
  - 欄位下方保留一整頁候選字視窗的高度，打字時版面不動。比欄位寬的視窗（例如字多的橫式清單）整個縮小。
  - 任務完成時，外框在 0.2 秒內變成綠色，上方出現「完成」。
- **暫存資料**：
  - 欄位使用自己的引擎，詞庫與模型和輸入法相同；
  - 記住的字詞、自訂詞、改字記錄與使用統計都寫在暫存目錄中的一個資料夾，最後一個練習欄位關閉時刪除；
  - 設定只存在記憶體中（`MemorySettingsStorage`）；
  - 欄位不讀系統的安全輸入狀態。
- **VoiceOver**：欄位是文字欄位，值是送出的文字加上組字。候選字是可以按的項目；清單開著時，讀出反白的候選字與位置（例如「名，第 1 個，共 23 個」）以及提示。
- **動態**：候選字視窗與中英提示跟著暫存設定的「動畫」，「減少動態效果」時只淡入淡出；「完成」的勾號在「減少動態效果」時也只淡入。
- **測試與預覽**：
  - 自我測試以合成的按鍵事件檢查：任務完成、設定立即生效、VoiceOver 讀到的內容，以及使用者的設定與資料檔案的路徑與修改時間都沒有改變。按鍵在程式內直接交給欄位，不送到系統。
  - `ZhuyinType --render-ui <資料夾> --only practice` 畫出幾個狀態的淺色與深色畫面，不取得焦點。

和真正的 App 相比，練習欄位做不到這些：

- 插入點固定在文字的結尾。← → 只在組字中移動游標，不能把游標移到已送出的文字中間，也不能用滑鼠點選文字中的位置。
- 沒有剪下、拷貝、貼上與復原；⌃ 加字母的游標移動（例如 ⌃A）沒有作用。
- 不示範「在候選字視窗顯示組字的 App」，也不示範各 App 回報游標位置的差異。
- 欄位的引擎是另外載入的一份，開始時沒有記住的字詞，所以選字結果可能和平常在 App 中看到的不同。
- 改變設定時，開著的清單回到第一頁；在 App 中，改變設定會關閉清單。
- 在「我在家」中把「在」改成「再」時，引擎會依新的字重新轉換後面的字（這份詞庫得到「我再加」），所以「改字」課程的題目可能需要讓使用者再改一次「家」，或改用不受影響的句子。

## 9. 版面

- 歡迎：App 圖示與標題，快速設定與完整導覽兩張卡片，下面是自動播放的候選字視窗預覽（真正的元件）。
- 習慣組合：四張卡片，每張以按鍵圖示列出它的習慣；下方即時列出會改變的設定。
- 課程：左邊是選擇（互斥的方式是一列一個選項，可以同時有效的是勾選），右邊是這一課的示範：真正的候選字視窗預覽，或設定頁 ⓘ 中的同一個示範；下面是練習。
- 確認：勾號以彈性動畫出現，接著每一列依序淡入上移，再顯示「全部捨棄」與「套用」。
- 按鍵：依用途分成「打字」「候選字清單」「改字與選取」的卡片。
- 每一步的主要按鈕（開始、下一步、套用、完成）是強調色；「略過這一步」「全部捨棄」是次要按鈕。

## 10. 動態

- **換步驟**：新的一步從右邊滑入 24 pt 並淡入，上一步向左移 12 pt 並較快淡出，共 0.24 秒（ease-out）；按「上一步」時方向相反。
- **完成**：練習欄位外框在 0.2 秒內變成綠色，「完成」的勾號以彈性動畫出現；上方的進度點同時前進一格。
- **選擇改變時**：小動畫與練習欄位立即照新的設定重畫，變化的部分淡入。
- **確認頁**：「改回」的那一列淡出再淡入原本的值；全部改回時清單收合成一句「沒有要改變的設定」。
- 「減少動態效果」開啟時，以上都改成淡入淡出，沒有位移與彈性。嚮導的動態不受「動畫」設定影響（那個設定只管浮動視窗）。
