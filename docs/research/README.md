# 研究

ZhuyinType 以「選對字」為主要目標，用可重現的評測和其他開源注音輸入法正面比較，借用別人有效的做法，並把我們自己的每一次嘗試（成功或失敗）都記錄下來。

| 文件 | 內容 |
|---|---|
| [log.md](log.md) | 研究紀錄：依日期記錄每個實驗的做法、數字與決定 |
| [competitors.md](competitors.md) | 和靈犀注音（0c）、善解（shanjie）在同一批句子上的對打結果 |
| [program.md](program.md) | 超越計畫：從對手的研究中挑出來、依影響排序的工作，每項附驗收標準 |
| [catalogue/](catalogue/) | 對手研究的完整目錄（英文原始整理）：善解的研究紀錄、善解的合約與實驗、靈犀的技術報告與研究頁 |

## 規則

- **評測在 GPU 主機上跑**，用和 app 相同的引擎（Linux 版）與模型（ONNX），結果和 Mac 的差異 ≤ 0.2%（[EVALUATION.md](../EVALUATION.md)）。
- **開發集調參數，測試集只追蹤**：每個版本的 [ZhuyinBench](../benchmarks/) 用固定的測試集，但任何決定只看開發集；採用一項改變前，用成對檢定（`training/eval/stats.py`：McNemar、bootstrap 信賴區間、改壞率上界、最小可偵測效果）確認不是雜訊。
- **對手的程式只用來執行比較**：靈犀注音是 AGPL-3.0，只建置、執行，不複製任何程式碼；善解是 Apache-2.0，評測集依各檔授權引入並保留出處（`training/eval/sets/external/`），模型檔不使用（內含指紋）。兩邊公開的方法可以參考，實作是我們自己的。
- **每個想法都記錄**：做了什麼、數字、採用與否、原因。沒採用的也寫進 [log.md](log.md) 與 [MODEL.md §11](../MODEL.md#11-試過但沒採用)，避免重複嘗試。
