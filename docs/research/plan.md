# 研究計畫

依預期影響排序，列出 ZhuyinType 接下來要研究的題目。每項附上：

- 想法的來源：我們自己的評測，或閱讀靈犀注音、善解公開研究時得到的啟發（[related-work.md](related-work.md)、[catalogue/](catalogue/)）
- 做法
- 事先訂好的驗收標準

驗收標準一律是我們自己的絕對目標，只在有幫助時引用其他專案公布的數字作為參考點。版本對應見 [ROADMAP.md](../ROADMAP.md)。

## 現況

目前的長處：

- 按錯鍵與按鍵順序的容錯
- 長前文
- 逐字模型的分數直接進詞圖
- 聊天、百科兩個語言模型依前文混合
- 記憶體（29 MB）
- 熱載入與自動更新

目前的不足：

| 方面 | 現況 |
|---|---|
| 統計底子 | 只用引擎時口語 74%。A1 第一輪可到 80%，但整套 app 沒有提升 |
| 評測集 | 缺真實聊天句子 |
| 個人記憶 | 學過的字可能被重排推翻 |
| 延遲 | 長句的每鍵延遲仍高 |
| 功能 | 還沒有補標點與補全 |

0.4.0 已補上成對檢定（`nlp/eval/stats.py`）、重排門檻、選字後固定、安全輸入與在／再。

## A. 底子與紀律（0.4.x）

| # | 工作 | 來源 | 做法 | 驗收 |
|---|---|---|---|---|
| A1 | 統計底子 | 同句比較的結果；善解公開的詞庫稽核、期望次數斷詞 | 詞庫加入小麥注音資料（MIT）與專有名詞層。語言模型用期望次數（詞圖上的期望）重新斷詞與計數，語料換成真實台灣文字（lm_chat2、公共對話與逐字稿）。稽核「每個詞單獨打能不能贏」 | 只用引擎時口語 ≥ 82%，app 整體提升。參考點是靈犀統計引擎在同一批句子上的 82.3%。第一輪（0.4.0）未採用：只用引擎時口語從 71% 提高到 80%，但 app 沒有可測的提升，見研究紀錄 |
| A2 | 評測紀律 | 善解 methodology、靈犀封存測試 | ZhuyinBench 每版附和上一版的成對比較（改對、改壞、p 值、改壞率上界）。保留集分片、記使用次數、用完退役。引入善解的 CC0 評測集與真實打錯回報集。0.4.0 已完成 `stats.py`、善解評測集，以及隨發布執行的 ZhuyinBench。保留集輪替待做 | 每次發布頁面列出成對比較 |
| A3 | 保守的重排 | 善解 τ／δ 門檻；靈犀 harmful override | 0.4.0 已完成：τ = 8 時輸出不變，短句延遲從 24 ms 降到 15 ms。δ > 0 全部變差，因為我們的重排改對遠多於改壞，所以維持 0。待做：學過的字不被重排推翻，用改壞率上界檢查 | 改壞率 ≤ 0.5%，整句全對率不降 |
| A4 | 改選後其他字不動 | 善解 repick-freeze（+151／−19） | 0.4.0 已完成：選字後其他已顯示的字固定（不算手動選字）。`repick_eval.py` 模擬選字，40 段試跑中改壞其他字的比例從 5.0% 降到 2.5%。待做：選到跨在詞中間的字時，固定那個詞剩下的字 | 模擬「刪掉重打、改選」重播通過 |
| A5 | 延遲上限 | 靈犀 100 ms 退回、善解非同步重排 | 每鍵先顯示引擎結果，模型在時限內回來才套用。使用 int8 權重 | 25 音節每鍵 p95 ≤ 16 ms |
| A6 | 隱私與安裝 | 善解 Learning／Registration | 0.4.0 已完成：安全輸入（密碼欄位）時不讀前文、不學習。升級時若輸入法已在清單，就不重新註冊，避免 Caps Lock 切換失效。記錄檔的 bundle ID 標為私密 | 每條規則一個自動檢查 |
| A7 | 在／再等同音字 | 使用者回報 | 0.4.0 已完成：建立 26 組同音字的開發與測試集，v3 以可發布的來源微調。在／再測試集從 87.4% 提高到 91.5%，有前文時從 92.2% 提高到 94.7%，改壞 0。待做：句首「再＋動詞」（再試試看）在引擎分數就偏向「在」 | 困難類別明顯提升，一般開發集不降 |

## B. 免選字與補標點（0.5）

| # | 工作 | 來源 | 做法 | 驗收 |
|---|---|---|---|---|
| B1 | 排名微調 | 靈犀 listwise 微調（512 步、引擎分數在 softmax 內） | 用我們自己的前 16 句，以「整句正確」為目標微調 v2b 與 v3 的最後幾層，引擎分數一起進 softmax。之後再校準改壞次數 | 困難同音 +4 個百分點，改壞不增加 |
| B2 | 學習式融合 | 自己的規劃 | 各層分數為特徵訓練融合模型，取代手調權重，輸出整句信心 | 高於手調權重 |
| B3 | 補標點 | 靈犀注音的補標點模型（其報告 F1 0.820，段尾不補） | 在 v3 的雙向音節編碼器加標點頭，字之間與段尾都補，只在有把握時補 | F1 ≥ 0.84、precision ≥ 0.90，「。」「？」的 recall ≥ 0.65 |
| B4 | 免選字率 | 善解 KySS、靈犀省鍵率 | 逐鍵重播量「整句不選字的比例」與「顯示後被改掉」次數，列為主要指標 | 列為每版主要指標，並在同句比較中一併報告 |

## C. 補全、數字、預測（0.6）
