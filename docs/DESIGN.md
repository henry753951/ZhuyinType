# ZhuyinType 產品設計

ZhuyinType 是開源、在本機運作的 macOS 注音輸入法。

本文件是使用者看得到的部分：按鍵、狀態、預設值與介面。程式內部的流程見 [ARCHITECTURE.md](ARCHITECTURE.md)，演算法與模型見 [MODEL.md](MODEL.md)，還沒做的事見 [ROADMAP.md](ROADMAP.md)。

---

## 1. 設計原則

1. **每個按鍵都即時回應。** 按鍵、轉換與模型推論都在主執行緒同步完成（模型只用 CPU，每次數毫秒），畫面一次更新到最終結果；寫入個人資料在背景進行。
2. **單一行程。** 輸入法、引擎與模型在同一行程內直接呼叫，讓輸入方式切換快速、可靠。
3. **組字一律顯示在游標處。** 透過 marked text 呈現組字；浮動組字由使用者依應用程式設定。
4. **標準操作優先。** Backspace 逐字刪除、方向鍵移動游標、選字鍵選取候選字；容錯與選字模型沿用這套操作。
5. **集中設定。** 約 15 個核心選項依用途分頁，進階選項集中在「進階」。
6. **本機資料處理。** 輸入與個人詞彙在本機處理、儲存；記住的字詞可檢視、刪除、匯出、匯入。程式不連網路。

## 2. 功能規格

### 2.1 組字與按鍵

按鍵依使用頻率分四層，越常用的越靠近打字的手。方向鍵的規則只有一條：**上下在清單裡移動，左右沿著句子移動**。設定頁「快捷鍵」依目前設定列出同一份表。

**自訂**：打字用的鍵（注音、聲調、空白、Return、⌫、Esc、方向鍵）固定；只列一個字、列出修正、打出注音、翻頁（Tab）、選取、刪詞、送出並換行可以在「快捷鍵」重新指定，點按鍵後按下新的組合，與打字或其他功能衝突的組合會說明原因並拒絕；「還原預設值」回到下表。沒有指定給功能的按鍵交給 App。候選字視窗與設定頁的預覽都顯示目前指定的按鍵。

**狀態**：沒在組字 →（打注音）組字中 →（↓ 或空白）候選字清單 →（選字）組字中 →（Return）送出。候選字清單有兩個開關，預設都關，都在 Shift 加上下鍵：⇧↓「單字」（只列一個字）和 ⇧↑「修正」（列按錯修正與模糊音的字）。Option 不用在清單上：很多 App 把 Option 組合鍵當自己的快捷鍵，有的還會先於輸入法處理。視窗下方顯示目前要改的讀音和這兩個開關的按鍵，開著時以強調色顯示，也可以直接點。

**要改哪個字**：游標在句尾時改最後的字詞；游標移到句中時，↓ 要改的字（預設是游標右邊的字，可改成左邊）先以強調色底線標出。清單開著時，正在改的部分是強調色底線加淡色底，選到不同長度的詞時跟著變。

|---|---|---|
| 打字 | 注音鍵、聲調鍵 6 3 4 7 | 拼注音，空白是一聲；整句連續輸入，即時顯示最佳句子 |
| | Return | 送出整段（清單開著時選目前的字） |
| | ⌫ | 刪掉一個注音符號；已成字時刪游標前的字（清單開著時先關清單） |
| | ← → | 在組字中移動游標 |
| 改字 | ↓ 或空白 | 開啟候選字清單：只列照按鍵打出的詞與字，長的在前，再來是單字 |
| | 1–9（或 asdfghjkl） | 選字 |
| | ↑ ↓（直式清單）／← →（橫式） | 移動選取 |
| | ← →（直式清單） | 改前一個或後一個字，清單跟著移動、保持同一種清單 |
| | 空白、Tab、Page Down／Shift-Tab、Page Up（橫式另有 ↓／↑） | 下一頁／上一頁；空白翻到最後一頁後回到第一頁 |
| | Esc | 關閉清單 |
| 其他清單 | ⇧↓ | 只列一個字；清單開著時切換 |
| | ⇧↑ | 列出按錯修正與模糊音的字（排在前面），用一般的 ↑↓ 瀏覽；再按一次還原。點「⇧↑ 修正」也一樣 |
| | `` ` `` | 打出注音本身（清單開著時是選取的部分，否則是游標前的音節） |
| 少用 | 單按 Shift | 中英切換（左、右或兩側可設定） |
| | ⇧← ⇧→ 再按 Return | 選取一段加入自訂詞，不送出 |
| | Esc | 清除注音，再按清除整段組字（可設定只清注音） |
| | ⌥⌫ | 刪游標前一個詞 |
| | ⇧Return | 送出並換行 |
| | 符號鍵 | `[` `]` 是「」，`'` 是、，`\` 是＼，`=` 是＝ |
| | ⇧ + 符號鍵 | 全形標點：，。？：；！…『』——～（）＋｜＠＃＄％＆＊ |

| | ⇧ 空白 | 在組字中放一個空白 |
| | 標點上按 ↓ | 列出同類標點（，、；：…、半形與全形） |
| | ⌥ + 數字或符號鍵 | 鍵上印的符號：⌥-. 是「.」，⌥⇧-. 是「>」 |
| | Caps Lock | 英文，或依系統設定切換輸入法 |

**預設**：空白開清單、Esc 清整段、兩側 Shift 切換並顯示「中／英」（也可只用左或右，或不用）、開始時是中文、直式清單 1–9 選字、字級 18 pt、改游標右邊的字、按錯修正標準、模糊音全關、參考游標前的文字、記住選過的字詞。一段組字最多 60 個音節。

組字中沒有清單時，↑ 與 Tab 不做事也不交給 App；沒有組字時，`` ` `` 交給 App。

### 2.2 容錯輸入
- 自動處理按到相鄰鍵、多按、漏按、兩鍵順序打反（同一個音節裡或跨音節）、三四聲與二聲輕聲互換、一聲不按空白直接打下一個字。
- 幾乎同時按下（35 ms 內）的鍵，順序錯了或多按一鍵都很便宜；分開按的鍵視為真的這樣打。
- 精確符合按鍵的整句優先：修正過的整句要比最好的未修正整句多 4.0 分（引擎分數加選字模型分數）才成為首選。
- 修正過的候選只在修正清單出現（⇧↑ 或點「⇧↑ 修正」），旁邊以灰字標出修正後的注音。
- 選了修正過的候選，就記住「哪個鍵常按成哪個鍵」，下次同樣的錯更容易修正。
- 「按錯鍵修正」設定：關（只切音節，不修正）／標準／積極（修正成本為標準的 70%）。

### 2.3 選字
- 整句轉換：詞庫、語言模型、音節對字模型一起在詞圖上找最好的整句，再由整句選字模型依游標前的文字從前 16 句裡重新挑選。
- 語言模型有兩個：聊天用語與百科用語。沒有前文時以聊天為主（打 ㄏㄨㄛˋ ㄕˋ 是「或是」）；游標前的文字或最近在這個 App 打的字偏專業時，百科的比重跟著提高。
- 游標前的文字：組字開始時向 App 讀取最多 32 字；App 不提供時，用同一個 App 10 分鐘內送出的字。只放在記憶體中，可在設定關閉。
- 支援模糊音（ㄗ／ㄓ、ㄘ／ㄔ、ㄙ／ㄕ、ㄣ／ㄥ、ㄢ／ㄤ，可逐項開關）。同樣常用時完全符合的排前面，另一個詞明顯更常用時才換上。
- 「一」「不」打變調後的讀音也能找到（一直 ㄧˋ ㄓˊ、不要 ㄅㄨˊ ㄧㄠˋ）；罕用讀音的分數較低（「說」打 ㄕㄨㄟˋ 時，「睡」優先）。
- 一段組字送出後，下一段接著前面送出的詞選字；按了送給 App 的鍵、點進文字、切換輸入框或標點之後，才重新當作句首。

### 2.4 個人記憶
| 記住什麼 | 怎麼用 | 什麼時候學 |
|---|---|---|
| 選過的字詞 | 同樣的讀音再打一次，直接用你選過的寫法（整段、部分、修正、詞庫沒有的詞） | 手動選字、送出後刪掉重打 |
| 個人一、二、三連詞 | 調整語言模型：什麼詞後面你常接什麼 | 每次送出；手動選字權重高，直接送出權重低 |
| 刪掉重打 | 送出後 30 秒內刪掉再打成別的字，舊的寫法在原本的前文減半 | 送出後的短時間內 |
| 按錯習慣 | 常把哪個鍵按成哪個鍵，修正成本跟著降低 | 選了修正過的候選 |

- 短期與長期：個人連詞同時有 8 小時與 90 天兩種半衰期；手動選過 3 次以上的保留最低分數。
- 容量：選過的字詞約 20,000 筆、個人連詞 50,000 筆，滿了先刪分數最低的。
- 設定頁「記住的字詞」：搜尋、移除、全部清除、不再記住（之後送出也不學）、匯出／匯入（自訂詞、記住的字詞、個人連詞、不記住的清單與按錯習慣存成一個文字檔）、暫停學習。

### 2.5 其他
- 自訂詞：在設定頁加入，或在組字中用 ⇧← ⇧→ 選取 1–6 個字後按 Return；加入後馬上生效。
- 標點一律為全形（見 §2.1），在標點上按 ↓ 可換成同類的其他寫法。
- 中英混打、Emoji、符號表、繁簡輸出尚未提供，見 [ROADMAP.md](ROADMAP.md)。

## 3. 系統整合

完整的逐鍵流程、分數公式與模型位置見 [ARCHITECTURE.md](ARCHITECTURE.md)。這裡只列和 macOS 文字客戶端有關的規則。

- **單一行程。** 輸入法、引擎與模型在同一行程內直接呼叫；引擎與模型在背景載入，載入完成前按鍵直接交給 App。
- **組字**：透過 `setMarkedText` 傳遞，只在文字、游標或底線改變時更新；網頁引擎型 App 也一樣。浮動組字（顯示在候選字視窗上方）依 App 的 bundle ID 設定，在「進階」檢視與修改。
- **單按 Shift**：`flagsChanged` 依實體按鍵狀態判斷，0.35 秒內放開才算單按；相同狀態的事件合併處理。
- **候選字視窗位置**：依序採用組字起點的行高矩形、游標前的組字、組字起點、選取範圍、上一次有效位置、滑鼠位置。
- **個人資料**：`~/Library/Application Support/ZhuyinType/` 下的 `user_phrases.tsv`、`learned.tsv`、`excluded.tsv`、`typos.tsv`、`personal_ngrams.tsv`，在背景以原子寫入更新。
- **設定**：UserDefaults。

## 4. UI

整體採用 macOS 26 之後的系統設計語言；以 macOS 27 SDK 建置並標記實際 SDK 版本，系統會以目前的樣式繪製所有標準控制項。

- **候選字視窗**：NSPanel，背景在 macOS 26 以上為 Liquid Glass（`NSGlassEffectView`），較舊系統為 popover 材質。直式或橫式、字級可調，選取列為強調色圓角矩形。
  - 上方：要改的字的注音（可點），標出聲調。
  - 清單：修正過的候選旁以灰字標出修正後的注音。
  - 下方固定：頁碼與 ‹ › 翻頁按鈕、「⇧↓ 單字」「⇧↑ 修正」兩個開關（開著時以強調色顯示，可點），按鍵依目前的快捷鍵設定顯示。
  - 需要時在下方顯示一行提示。
- **狀態提示**：中英切換時在游標旁以同樣的玻璃材質顯示「中」或「英」0.8 秒。
- **App 圖示**：Icon Composer 格式（`Resources/AppIcon.icon`），藍色背景加上一層玻璃材質的「ㄓ」字形（取自 PingFang TC），由系統渲染淺色、深色與透明外觀；`scripts/make_icons.swift` 產生並以 actool 編譯。
- **輸入法圖示**：16 × 16 pt 正方形、2.5 pt 圓角，鏤空細字重的「ㄓ」，比例與系統內建輸入法相同；為 template 向量 PDF，選單列、輸入法選單與游標旁的指示器由系統著色。
- **設定視窗**：與系統設定相同的版面——左側原生 source list 側欄（彩色圖示），右側為 SwiftUI 分組表單。
  1. 一般：空白鍵、Esc、中英切換鍵、切換提示、開始時的語言、改游標左邊或右邊的字、按錯鍵修正、參考游標前的文字、模糊音。
  2. 快捷鍵：依頻率分組列出所有按鍵；可重新指定的功能點一下後按新的組合，衝突時說明原因；「還原預設值」。
  3. 候選字視窗：排列、字級、選字鍵，以及使用真實候選字視窗元件的預覽。
  4. 自訂詞：清單、加入、移除；工具列提供搜尋。
  5. 記住的字詞：開關、清單（依次數排序）、移除、不再記住、全部清除、匯出與匯入；工具列提供搜尋。
  6. 進階：以浮動視窗顯示組字的 App、回復預設設定。
  7. 關於：版本、授權、資料來源。
- **清單**：NSTableView（列重複使用，大量資料也流暢），版面比照系統設定的分組清單：主要文字在前、次要值在後、列間內縮分隔線；底部為 ＋／－，支援多選與 Delete 鍵。

## 6. 授權

- 程式碼：AGPL-3.0-only。
- 詞庫：只使用允許再散布的開放資料，每個來源記錄在 `data/SOURCES.md`（網址、版本、授權、署名）。
- 模型：訓練資料與各自的授權列在 `data/SOURCES.md`，條款隨模型一起放進 app（`Contents/Resources/lm_chat/` 等）。

開發階段與後續規劃見 [ROADMAP.md](ROADMAP.md)。
