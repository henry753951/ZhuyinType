# ZhuyinType 0.7.7

發布日期：2026 年 11 月 26 日
系統需求：macOS 14 或更新版本（Apple 晶片）；Windows 10、11（x64）；Debian 13、Ubuntu 25.04、Fedora 42、openSUSE Tumbleweed 或更新版本（x86_64，Fcitx 5）

## 新功能

- **更新內容提示**：更新後第一次打字停下來時，提示這一版改了什麼，每一版只提示一次。組字中、密碼欄位與全螢幕時不會出現，也不會取走焦點。可以在「關於 › 更新內容」關閉。
- **意見與問題**：「關於 › 意見與問題」與輸入法選單的「回報問題…」直接開啟 GitHub 上的回報頁面，並填好版本與系統。診斷資料由你看過後自己貼上，不會自動送出。
- **移除的原因**：移除 ZhuyinType 時可以選填原因，幫助我們改進。Windows 在解除安裝的最後一頁，macOS 與 Linux 在「關於 › 移除 ZhuyinType」。

## 改進

- 「送出後列出聯想詞」更新後一律關閉一次。想要使用的話，可以再到設定開啟。

## 修正

- 自訂詞省略一聲的空白時也能打對，例如加入「徐禕佑」後，打 ㄒㄩˊㄧㄧㄡˋ 不再變成「徐佑」。
- 打錯的鍵更常被改對，例如按到旁邊的鍵，或把前後兩個音節的鍵打反。
- 打字時按到旁邊的鍵，不再被當成多按了一個鍵而變成別的詞，例如「新蘆線」變成「因路線」。

## 已知問題

- 自訂詞的聲調打錯或沒打聲調時，仍可能打成別的字。請打正確的聲調，或從候選字清單選取。
- 「貼上」「下載」這類詞，從修正清單選錯一次仍會被記住。再打一次並選回正確的字，或在候選字上按右鍵選「忘記這個選字」，就會恢復。
- 打「專案」時省略一聲的空白，仍可能打成別的字。打完 ㄓㄨㄢ 按一次空白就正確。
- Windows：不認得的遊戲在視窗模式下，注音仍顯示在螢幕左上角的小框裡（Windows 本身的做法）。可以把它加進「進階 › 在候選字視窗顯示組字的 App」。
- Windows：有些遊戲在遊玩畫面關掉視窗的輸入法（也有模組這樣做），這時選了 ZhuyinType 也打出英文字母；打開遊戲的聊天後，遊戲會重新開啟輸入法。微軟注音也一樣。
- Windows：更新前已經開著的 App 沿用舊版，重新開啟後換成新版。
- 簡體輸出是逐字轉換，沒有詞語對照，例如「乾坤」會寫成「干坤」。
- Linux 的 Wayland 工作階段中，符號與 Emoji 面板以候選字清單呈現（一次一列），候選字視窗不跟著主題。

## 準確率

按鍵都打對時，轉換結果與 0.7.6 相同（三個開發集共 1,200 句）。按鍵有打錯時，在兩組未用來調整的口語與百科段落中，改對 179 段、改壞 4 段。見 [0.7.2 的發布說明](https://github.com/henry753951/ZhuyinType/blob/main/docs/releases/v0.7.2.md#準確率)。
