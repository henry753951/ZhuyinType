# ZhuyinType 0.6.0

發布日期：2026 年 11 月 16 日
系統需求：macOS 14 或更新版本（Apple 晶片）；Windows 10、11（x64）；Debian 13、Ubuntu 25.04、Fedora 42、openSUSE Tumbleweed 或更新版本（x86_64，Fcitx 5）

## 新功能

- **Windows 安裝程式**：下載一個安裝檔，按一次 UAC 即完成安裝，輸入法自動加入清單並在登入時啟動。可從「設定 → 應用程式」解除安裝，個人資料預設保留。64 位元與 32 位元的程式都能使用。
- **Linux 套件**：提供 `.deb` 與 `.rpm`，用 apt、dnf 或 zypper 安裝。Fcitx 5 等相依套件會一併安裝，登入後 ZhuyinType 會自動加入 Fcitx 5 的輸入方式。
- **新的 Windows 與 Linux 介面**：設定、設定嚮導與候選字視窗重新製作，功能與版面和 macOS 版相同。視窗使用 ZhuyinType 自己的標題列與外觀，淺色與深色都支援。
- **候選字視窗出現在任何地方**：Windows 的候選字視窗直接畫在你正在打字的程式裡，在開始功能表的搜尋框中也看得到。Windows 11 上有圓角、陰影與半透明背景，和系統選單一致。
- **看得出正在改哪個字**：Windows 與 Linux 的組字每個詞都有底線。候選字清單開著時，要換掉的詞會反白；游標移到句子中間時，按 ↓ 會改的詞以粗底線標出。

## 改進

- Windows 與 Linux 的候選字視窗支援直式與橫式、翻頁動畫、點選候選字，以及單字、修正清單的切換，和 macOS 版相同。
- 單按 Shift 切換中英時，游標旁會短暫顯示「中」或「英」。

macOS 版的功能與 0.5.3 相同。

## 已知問題

- Windows 與 Linux 版尚未使用神經模型，整句選字比 macOS 版容易選錯。選錯時按 ↓ 從候選字清單選取，選過的字詞會被記住。
- Windows 與 Linux 版沒有自動更新。有新版本時，請從發布頁下載安裝，設定與個人資料會保留。
- Windows 安裝程式尚未簽章，可能顯示「Windows 已保護您的電腦」。確認檔案來自本專案的發布頁後，選擇「其他資訊 → 仍要執行」。
- Linux 的 Wayland 工作階段由 Fcitx 5 顯示自己的候選字視窗，外觀和 X11 不同。
- 曾安裝 0.5.0 Windows 或 Linux 開發版的人，請先以舊版的 `install.ps1 -Uninstall` 或 `./install.sh --uninstall` 移除，再安裝這一版。

## 安裝

- macOS：0.4.0 以後的版本會自動更新。新安裝請下載 [ZhuyinType-macOS.pkg](https://github.com/henry753951/ZhuyinType/releases/download/v0.6.0/ZhuyinType-macOS.pkg)。
- Windows：下載 [ZhuyinType-Windows-x64-setup.exe](https://github.com/henry753951/ZhuyinType/releases/download/v0.6.0/ZhuyinType-Windows-x64-setup.exe) 並執行。
- Debian、Ubuntu：下載 [ZhuyinType-Linux-amd64.deb](https://github.com/henry753951/ZhuyinType/releases/download/v0.6.0/ZhuyinType-Linux-amd64.deb)，執行 `sudo apt install ./ZhuyinType-Linux-amd64.deb`。
- Fedora、openSUSE：下載 [ZhuyinType-Linux-x86_64.rpm](https://github.com/henry753951/ZhuyinType/releases/download/v0.6.0/ZhuyinType-Linux-x86_64.rpm)，執行 `sudo dnf install ./ZhuyinType-Linux-x86_64.rpm` 或 `sudo zypper install ./ZhuyinType-Linux-x86_64.rpm`。

各系統的安裝、移除步驟與系統需求見 [README](https://github.com/henry753951/ZhuyinType#安裝)。檔案的 SHA-256 檢查碼在 `SHA256SUMS-desktop.txt`。
