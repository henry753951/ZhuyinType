# ZhuyinType 0.5.3

發布日期：2026 年 11 月 9 日
系統需求：macOS 14 或更新版本

## 修正

- 修正右 Shift 單按無法切換中英的問題，適用於「左右 Shift」與「右 Shift」設定。

## 已知問題

- Caps Lock 與 macOS 原生切換的實際操作仍需持續確認；若切換後模式不符預期，可從選單列重新選擇輸入方式。
- App 採 ad-hoc 簽章，安裝套件尚未簽署與公證。若 macOS 顯示安全性提示，請至「系統設定 → 隱私權與安全性」查看開啟選項。

## 安裝

- 已安裝 0.4.0 以後版本者，可透過自動更新取得。
- 新安裝：下載並開啟 [ZhuyinType-macOS.pkg](https://github.com/henry753951/ZhuyinType/releases/download/v0.5.3/ZhuyinType-macOS.pkg)。
- Windows 與 Linux 的編譯成品暫停提供；本次僅發布 macOS 版本。
