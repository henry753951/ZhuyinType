# ZhuyinType 0.6.1

發布日期：2026 年 11 月 17 日
系統需求：macOS 14 或更新版本（Apple 晶片）；Windows 10、11（x64）；Debian 13、Ubuntu 25.04、Fedora 42、openSUSE Tumbleweed 或更新版本（x86_64，Fcitx 5）

## 修正

- Windows 與 Linux：關閉設定視窗或設定嚮導後，就無法再輸入注音。現在關閉視窗不會影響輸入。
- Windows 與 Linux：在沒有輸入框的地方切換中英時，「中」「英」提示會出現在螢幕角落。現在只在輸入框旁顯示；從工作列切換時也會顯示在目前的輸入框旁。

macOS 版的功能與 0.6.0 相同。

## 安裝

- 已安裝 0.6.0 的 Windows 與 Linux，以及 0.4.0 以後的 macOS，會自動更新。
- 0.6.0 在 Windows 或 Linux 上若已無法輸入注音，請登出再登入一次，背景程式會重新啟動並收到這次更新；或從開始功能表開啟「ZhuyinType 設定」，在「關於」按「立即檢查」。
- 新安裝：[macOS](https://github.com/henry753951/ZhuyinType/releases/download/v0.6.1/ZhuyinType-macOS.pkg)、[Windows](https://github.com/henry753951/ZhuyinType/releases/download/v0.6.1/ZhuyinType-Windows-x64-setup.exe)、[Debian／Ubuntu](https://github.com/henry753951/ZhuyinType/releases/download/v0.6.1/ZhuyinType-Linux-amd64.deb)、[Fedora／openSUSE](https://github.com/henry753951/ZhuyinType/releases/download/v0.6.1/ZhuyinType-Linux-x86_64.rpm)。
