# ZhuyinType 0.5.2

發布日期：2026 年 11 月 7 日
系統需求：macOS 14 或更新版本

## 改進

- 「設定 → 打字」直接列出標點全半形與插入半形空白的快捷鍵，並附上全半形示範。
- 「快捷鍵」總覽將標點與符號移到前面，搜尋支援「全型」「半型」與修飾鍵名稱，也能找到第二、第三組自訂按鍵。
- 「介紹」與「新功能導覽」補上標點全半形的說明，示範跟著目前指定的快捷鍵更新。

## 修正

- 同一個 App 最近一分鐘的前文會與輸入框文字合併，最多保留 255 字。輸入框清空、換輸入框或讀不到文字時，仍可接續剛才送出的內容選字；重複部分只保留一份。
- Caps Lock 的暫時英文狀態與輸入法本身的中英模式分開保存，切換輸入框時沿用正確的模式。
- macOS 切到其他輸入方式後，忽略延遲送到的修飾鍵事件。Caps Lock 也會取消尚未完成的 Shift 單按判斷。

## 已知問題

- Caps Lock 與 macOS 原生切換的實際操作仍需持續確認；若切換後模式不符預期，可從選單列重新選擇輸入方式。
- App 採 ad-hoc 簽章，安裝套件尚未簽署與公證。若 macOS 顯示安全性提示，請至「系統設定 → 隱私權與安全性」查看開啟選項。

## 安裝

- 已安裝 0.4.0 以後版本者，可透過自動更新取得。
- 新安裝：下載並開啟 [ZhuyinType-macOS.pkg](https://github.com/henry753951/ZhuyinType/releases/download/v0.5.2/ZhuyinType-macOS.pkg)。
- Windows 與 Linux 的編譯成品暫停提供；本次僅發布 macOS 版本。
