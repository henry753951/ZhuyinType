# ZhuyinType 0.4.0

這一版集中在四件事：在／再選對、輸入法變輕變快、真實口語的聊天模型，以及之後自動更新的基礎。從這一版起，新版本會在你沒在打字時自動換上。

## 新功能與改進

- **在／再**：選字模型針對在、再重新訓練（只用可再散布的資料）。在／再測試集 87.4% → 91.5%（有前文 92.2% → 94.7%），改對 43 句、改壞 0 句；句首的「再」（再等我五分鐘）48% → 70%。另外 25 組常見同音字（做／作、已／以、他／她／它……）也小幅提高。
- **自動更新**：使用 Sparkle（EdDSA 簽章、差分更新）。有新版時在閒置時自動安裝並重新啟動輸入法，不打斷打字；「設定 → 關於 → 更新」可以關閉自動檢查或自動安裝，或立即檢查。模型與資料檔更新後會自動重新載入，載入期間的按鍵不會遺失。
- **記憶體**：詞庫與語言模型改成直接對應檔案（mmap），輸入法常駐記憶體 222 MB → 約 29 MB，載入 1.25 秒 → 0.08 秒。
- **每鍵延遲**：整句重排改用前綴樹一次算完 16 句、只多打注音符號時沿用上一次結果、引擎很有把握時不跑重排。10 個音節每鍵 p95 34 → 約 15 ms，25 個音節 53 → 33 ms，每鍵能耗少約 36%。
- **聊天模型 v2**：改用真實的台灣口語文字（立法院公報逐字稿、維基百科討論頁、Common Voice），不再含產生的句子與 Taiwan Tongues。
- **選字後其他字不動**：從清單選字後，其他已經顯示的字不會被重新排序改掉。
- **「台／臺」**：預設寫「台」，清單裡兩種寫法合併；在「設定」可改成「臺」。
- **更長的前文**：讀取游標前約 120 個字（原本 32 字）。
- **隱私**：在密碼欄位（安全輸入）時不讀前文、不學習；記錄檔不公開 App 的 bundle ID。
- **安裝**：升級時如果輸入法已在清單中，就不重新註冊，避免 Caps Lock 切換失效。
- **圖示**：輸入法圖示改成系統比例（16 × 16 pt）。

## 準確率（測試集，整句全對率）

每組 400 句（日常短句 68 句），同一批注音輸入，0.3.0 與 0.4.0 的模型和設定在同一個引擎上執行；改對／改壞是成對比較，p 為精確 McNemar 檢定。

| 測試集 | 0.3.0 | 0.4.0 | 改對／改壞 | p |
|---|---|---|---|---|
| 口語 | 82.2% | **83.5%** | 9／4 | 0.27 |
| 維基百科 | 81.0% | 81.2% | 10／9 | 1.0 |
| 維基百科（有前文） | 85.0% | **86.5%** | 12／6 | 0.24 |
| Taiwan Tongues | 74.5%（85.8%） | 73.2%（84.5%） | 6／11 | 0.33 |
| 日常短句 | 100% | 100% | 0／0 | — |
| 在／再（沒有前文） | 87.4% | **91.5%** | 43／0 | < 1e-7 |
| 在／再（有前文） | 92.2% | **94.7%** | 26／0 | < 1e-7 |

- 括號內是「台／臺」等寫法視為相同的分數。一般測試集的差異都在雜訊範圍內；在／再的提升是顯著的。
- Taiwan Tongues 略降：0.3.0 的聊天模型含 Taiwan Tongues 的訓練文字（同一來源），0.4.0 為了授權拿掉了。
- 這一版引入善解以 CC0 釋出的評測集（感謝善解專案與同意釋出回報句子的使用者），並和靈犀注音、善解在同一批句子上做了比較。比較的條件與限制（例如各自建立的集合對自己有利、功能範圍不同）見 [research/related-work.md](../research/related-work.md)。

完整的逐版評測（ZhuyinBench：轉換、按錯鍵、候選字、改選、善解的評測集）在 [docs/benchmarks](../benchmarks/)，CPU、能耗與記憶體附在這一版的 `metrics-mac.json`。

## 安裝

第一次安裝用 `ZhuyinType-0.4.0.pkg`。之後的版本會自動更新。

## 其他

- 專案結構：選字相關的程式（引擎、資料、訓練、評測、遠端評測）都在 `nlp/`，各平台的輸入法在 `clients/`。
- 試過但沒採用：小麥注音詞庫＋期望次數語言模型（只用引擎時口語 71% → 80%，但整套 app 沒有可測的提升）。紀錄在 [research/log.md](../research/log.md)。
- 還沒解決：沒有前文時「再試試看」仍會打成「在試試看」，列在 0.5 的計畫（[ROADMAP.md](../ROADMAP.md)）。
