# ZhuyinType 0.4.0

發布日期：2026 年 10 月 27 日
系統需求：macOS 14 或更新版本

## 新功能

- **自動更新**：有新版本時，ZhuyinType 會在你停止打字後自動下載並安裝，不需要重新登入或重新選擇輸入法。可在「設定 → 關於」關閉自動檢查、自動安裝，或手動檢查更新。
- **「台」與「臺」**：預設使用「台」，可在「設定」改為「臺」。候選字清單把兩種寫法合併成一項。

## 改進

- 「在」與「再」選得更準確，例如「我在路上」「再等我五分鐘」。
- 記憶體用量從約 222 MB 降到約 29 MB，輸入法啟動更快。
- 打字的反應更快，長句尤其明顯。
- 口語選字更貼近台灣的日常用語。
- 從候選字清單選字後，其他已顯示的字保持不變。
- 選字時會參考游標前更長的一段文字。
- 在密碼欄位中，ZhuyinType 不讀取前文，也不記住輸入的內容。
- 系統記錄中不顯示你正在使用的 App。

## 修正

- 修正升級後用 Caps Lock 切換中英文可能失效的問題。
- 選單列的輸入法圖示改為與系統一致的大小。

## 已知問題

- 沒有前文時，「再試試看」可能顯示為「在試試看」。請從候選字清單選取「再」，ZhuyinType 會記住你的選擇。

## 準確率

整句完全正確的比例，每組 400 句（日常短句 68 句）：

| 測試集 | 0.3.0 | 0.4.0 |
|---|---|---|
| 在／再（沒有前文） | 87.4% | 91.5% |
| 在／再（有前文） | 92.2% | 94.7% |
| 口語 | 82.2% | 83.5% |
| 維基百科（有前文） | 85.0% | 86.5% |
| 維基百科 | 81.0% | 81.2% |
| Taiwan Tongues | 74.5% | 73.2% |
| 日常短句 | 100% | 100% |

除了在／再，其他測試集的差異都不顯著。完整結果與評測方法見 [ZhuyinBench 0.4.0](https://github.com/henry753951/ZhuyinType/blob/main/docs/benchmarks/v0.4.0.md)。

## 安裝

- **新安裝，或從 0.3.0 升級**：下載並開啟 `ZhuyinType-0.4.0.pkg`。
- **0.4.0 以後的版本**：都會自動更新。
