# ZhuyinType 0.5.1

發布日期：2026 年 11 月 6 日
系統需求：macOS 14 或更新版本

## 新功能

- **標點全半形**：中文模式預設全形標點，按 Shift＋空白切換全形與半形。英文字母、數字與空白維持半形；英文模式使用半形。

## 改進

- 組字中插入半形空白的預設快捷鍵改為 Option＋空白。兩個快捷鍵都可在「設定 → 快捷鍵」重新指定。
- 「設定 → 打字」可選擇標點按法，「標點與符號」頁面列出全半形的切換方式。

## 修正

- 改選同音詞後，依新的選擇更新記憶；在不同前文選過不同詞時，依相同位置的前文偏好選字，保留其他位置的記憶。
- 開啟改字記錄時，保留實際選取的候選詞、讀音與範圍，以及標點全半形的切換，供後續分析。

## 已知問題

- 兩個字之間的按鍵對調，仍可能需要按 Delete 重打，或從候選字清單選取。
- App 採 ad-hoc 簽章，安裝套件尚未簽署與公證。若 macOS 顯示安全性提示，請至「系統設定 → 隱私權與安全性」查看開啟選項。

## 安裝

- 已安裝 0.4.0 以後版本者，可透過自動更新取得。
- 新安裝：下載並開啟 [ZhuyinType-macOS.pkg](https://github.com/henry753951/ZhuyinType/releases/download/v0.5.1/ZhuyinType-macOS.pkg)。
- Windows 與 Linux 的編譯成品暫停提供；本次僅發布 macOS 版本。
