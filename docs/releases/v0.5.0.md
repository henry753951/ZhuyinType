# ZhuyinType 0.5.0

發布日期：2026 年 10 月 29 日
系統需求：macOS 14 或更新版本；Windows 10、11（x64）；Linux x86_64，Fcitx 5 與 Qt 6.8 以上

這一版開始支援 Windows 與 Linux。三個平台使用同一套設定項目、快捷鍵與候選字視窗設計。

## 新功能

- **Windows**：以 TSF 輸入法安裝，支援 Windows 10、11（x64）。工作列的輸入指示器左格顯示「中」／「英」，按一下切換，右鍵選單可開啟設定；右格是 ZhuyinType 標誌。
- **Linux**：以 Fcitx 5 附加元件安裝，支援 X11 桌面的 Xfce、GNOME、KDE 工作階段。
- **共用設定**：三個平台的設定頁面、快捷鍵、字詞管理與候選字視窗使用同一套設計。
- **授權與資料來源**：三個平台都能在 App 內閱讀授權全文與資料來源清單。
- **改字記錄與使用統計**：與 macOS 相同格式，只記錄次數與時間，可在設定中開啟、匯出或清除。

## 改進

- 設定介面重新設計，列、卡片與按鈕的間距與 macOS 版一致。
- 快捷鍵只儲存你改過的按鍵；單一功能可還原為預設，衝突時會列出。
- 候選字視窗可依設定顯示在游標上方或下方，支援直式與橫式清單。
- 前文：macOS 與 Linux 會讀取游標前的文字；同一個 App 十分鐘內送出的字會保留。Windows 目前只區分 App，尚未讀取游標前的文字。

## 已知問題

- macOS：pkg 的簽署與公證尚待完成，套件使用建置機的架構。
- Windows：安裝檔尚未簽章，首次執行可能出現 SmartScreen 提示。
- Windows：工作列指示器的右鍵選單尚未完整測試；開始功能表捷徑與打字、Shift 切換已在測試環境確認。
- Linux：Wayland 工作階段尚未支援，服務會顯示提示並停止。候選字視窗目前在 X11 上運作。
- 兩個字之間的按鍵對調，仍可能需要按 Backspace 重打，或從候選字清單選取。

## 安裝

- macOS：下載 `ZhuyinType-macOS.pkg`（或 `ZhuyinType-0.5.0.pkg`），開啟後依指示安裝。0.4.0 以後的版本會自動更新到這個版本。
- Windows：下載 `ZhuyinType-Windows-x64.zip`，解壓縮後執行 `install.ps1`。
- Linux：下載 `ZhuyinType-Linux-x86_64.tar.gz`，解開後執行 `./install.sh`。

詳細步驟見 [README](../../README.md#安裝)。
