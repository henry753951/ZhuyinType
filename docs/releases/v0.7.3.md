# ZhuyinType 0.7.3

發布日期：2026 年 11 月 21 日
系統需求：macOS 14 或更新版本（Apple 晶片）；Windows 10、11（x64）；Debian 13、Ubuntu 25.04、Fedora 42、openSUSE Tumbleweed 或更新版本（x86_64，Fcitx 5）

## 改進

- Windows：在遊戲裡打字看得到注音了。Minecraft（Java 版）和許多遊戲不告訴輸入法文字在哪裡，以前注音出現在螢幕左上角的小框裡，全螢幕時看不到；有些遊戲則完全不顯示。現在 ZhuyinType 偵測到這種視窗時，注音和候選字改在遊戲視窗左下角的懸浮打字框顯示（聊天列通常在那裡），遊戲只收到送出的字。可在「進階 › 相容性」關閉「看不到注音時改用懸浮打字框」。
- Windows：在全螢幕的遊戲裡切換到 ZhuyinType 時，左下角顯示「中」或「英」。Windows 自己的切換提示和工作列在全螢幕時被遊戲擋住，以前看不出切換了沒有。

## 已知問題

- Windows：有些遊戲在遊玩畫面關掉視窗的輸入法（也有模組這樣做）。這時 Windows 不把按鍵交給任何輸入法，選了 ZhuyinType 也打出英文字母；打開遊戲的聊天後，遊戲會重新開啟輸入法。微軟注音也一樣。
- Windows：懸浮打字框依視窗是否提供游標與組字位置判斷。少數自己在畫面上顯示組字、卻不提供這些資訊的遊戲，注音會同時出現在遊戲裡和懸浮打字框；可關閉上面的設定。
- Windows：更新前已經開著的 App（包括遊戲）沿用舊版，重新開啟後換成新版。
- 簡體輸出是逐字轉換，沒有詞語對照，例如「乾坤」會寫成「干坤」。
- Linux 的 Wayland 工作階段中，符號與 Emoji 面板以候選字清單呈現（一次一列），候選字視窗不跟著主題。
