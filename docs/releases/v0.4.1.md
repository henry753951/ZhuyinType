# ZhuyinType 0.4.1

發布日期：2026 年 10 月 27 日
系統需求：macOS 14 或更新版本

## 新功能

- **標點按法**：可在「設定」的「一般」選擇 Windows 或 macOS 的按法，預設為 Windows。
  - Windows：和 Windows 的微軟注音相同。Shift 加符號鍵打出鍵上印的符號，例如 Shift 加減號鍵是「_」，可以直接打出「T_T」；Control 加符號鍵打出中文標點，例如 Control 加逗號是「，」、加句點是「。」、加引號鍵是「、」，Control-Shift 加斜線鍵是「？」。
  - macOS：和 macOS 內建注音相同，Shift 加逗號是「，」、Shift 加減號鍵是「——」。習慣原本按法的使用者請改選這一項。

## 改進

- 從候選字清單選了詞中間的一個字時，同一個詞在它前面、你已經看過的字保持不變。
- 你在同一個位置選過的詞，之後打同一句時不會被換掉。

## 修正

- 修正改選別的字之後，原本顯示的字沒有在個人記憶中減弱，下次仍可能優先出現的問題。

## 安裝

- 0.4.0 會自動更新到這個版本。
- 新安裝：下載並開啟 `ZhuyinType-0.4.1.pkg`。
