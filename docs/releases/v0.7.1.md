# ZhuyinType 0.7.1

發布日期：2026 年 11 月 18 日
系統需求：macOS 14 或更新版本（Apple 晶片）；Windows 10、11（x64）；Debian 13、Ubuntu 25.04、Fedora 42、openSUSE Tumbleweed 或更新版本（x86_64，Fcitx 5）

## 新功能

- **新的設定版面**：側欄分成「概覽」「輸入」「選字與字詞」「外觀」「一般」五段、十四頁，一頁管一件事：「打字」分成打字、標點與符號、中英切換；「選字」分成選字、修正、字詞；「視窗與提示」分成候選字視窗與色彩；「檢查輸入法」在側欄自成一項，有需要處理的項目時旁邊出現警示符號。0.7.0 的功能放到相關的設定旁：「符號與 Emoji」在「標點與符號」，「快速設定」在「中英切換」，「暫停學習」與候選字的字詞動作在「字詞」，主題、透明效果與強調色在「色彩」。每個可以自訂按鍵的功能，在自己那一頁就能改按鍵；「快捷鍵」頁依同樣的頁面分段，列出所有按鍵。
- **連結直接到那一列**：從「介紹」的功能卡片、「快捷鍵」、設定嚮導或其他頁面點連結，設定視窗切換到那一頁、捲到那一列並亮一次，鍵盤焦點也在那一列上，可以直接用鍵盤調整。從「快捷鍵」的一列可以回到功能所在的頁面，反過來也一樣。
- **詳細的檢查輸入法**：每個檢查項目下方的「詳細資料」列出檢查了什麼、看到的值，例如文字服務的位置、這位使用者的輸入法清單、Fcitx 5 的版本與詞庫檔案。「回報問題…」的內容改為 Markdown，貼到 GitHub 時顯示成標題與清單，並加上資料版本、安裝位置、輸入法、更新、改過的設定與顯示設定；家目錄與使用者名稱都會隱去，仍不含打過的字、自訂詞或記住的字詞。

## 改進

- 聯想詞的選字方式更清楚：清單剛出現時不標選字鍵，標題寫「聯想詞・按 ↓ 選擇」，這時 1–9 照常打注音（1 仍是 ㄅ）。按 ↓ 進入清單後，詞前面才標出選字鍵，例如按 ↓ 再按 2 送出第二個詞。
- Windows 與 Linux：設定視窗的捲動和 Edge、Chrome 一樣平順，滾輪每一格、Page Up／Page Down 與連結的捲動都以動畫移到位置；觸控板照手指移動。系統開啟「減少動態效果」時直接跳到位置。

## 修正

- Windows：開啟聯想詞時，部分 App 中送出後的第一個 Return、方向鍵或 Ctrl 快捷鍵沒有作用，例如按 Return 沒有換行。現在聯想詞清單只接收 ↓，其他按鍵照常交給 App。
- Windows 與 Linux：開啟透明效果（Windows 11 的 Mica、KDE Plasma 的背景模糊）時，設定視窗的對話框是透明的，看得到後面的頁面，文字不易閱讀。現在提示、授權與資料來源、回報問題的對話框都有不透明的底色。

## 已知問題

- 簡體輸出是逐字轉換，沒有詞語對照，例如「乾坤」會寫成「干坤」。
- Windows 與 Linux 的符號與 Emoji 面板預設為 Ctrl+Shift+/，macOS 是 ⌃⌥,。可以在「快捷鍵」改成其他按鍵。
- Linux 的 Wayland 工作階段中，符號與 Emoji 面板以候選字清單呈現（一次一列），候選字視窗不跟著主題。
